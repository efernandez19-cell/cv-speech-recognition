# Computer Vision & Speech Recognition — Homework

## Clinical Task
The goal is to classify dermoscopic skin lesion images from the MILK10k dataset
(ISIC archive) into diagnostic categories such as melanoma, basal cell carcinoma,
and others. This supports dermatologists in the early detection of skin cancer,
where timely and accurate classification can significantly improve patient outcomes.

## Session 1 — Exploratory Data Analysis
- Dataset overview: ~10,480 images, metadata, and 11-class ground truth labels
- Class distribution analysis (diagnosis_1 and subclasses)
- Age range and sex distribution per class
- Sample image visualization
